# NoiseStamp

**Training-Free Multi-Bit Watermarking for Streaming Text-to-Speech via Noise-Space Embedding**

## Demo

**[Visit the demo webpage](https://ns-demo27.github.io/NoiseStamp/)**

Listen to selected unwatermarked and watermarked speech from F5-TTS, IndexTTS2, CosyVoice3, and VoxCPM2. The webpage includes English and Chinese NoiseStamp examples, comparisons with six baseline methods on IndexTTS2, and a summary of the reported evaluation results.

Full recordings and one-second excerpts are available, with transcripts in the original language. These are illustrative listening examples, not a live watermark detection service.
